## Encode Text into Binary Code

The **Text to Binary Translator** converts standard alphabetical text into base-2 machine code. It breaks down every character of your input into its 8-bit ASCII equivalent.

### Why translate text to binary?
While humans read languages like English using a 26-letter alphabet, computer processors operate exclusively using electrical signals representing "on" or "off" (1 or 0). Converting text to binary is a great way to understand how computers store information at the lowest level. It is also a fun way to send "secret" messages to friends!

### Example Translations
* `A` = `01000001`
* `B` = `01000010`
* `Hello` = `01001000 01100101 01101100 01101100 01101111`
