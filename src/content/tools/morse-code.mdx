## How does the Morse Code Translator work?

Morse code is a method used in telecommunication to encode text characters as standardized sequences of two different signal durations, called dots and dashes (or dits and dahs). This tool automatically detects whether you are typing standard English or Morse code. 

If you type English text, it instantly translates it into the equivalent dots and dashes. If you paste dots and dashes (using the `/` symbol to separate words), it will decode it back into English.
