## What is Hexadecimal?

Hexadecimal (often shortened to "Hex") is a base-16 numbering system. Unlike our standard decimal system which uses 10 digits (0-9), hex uses 16 distinct symbols:
* The numbers `0` through `9`
* The letters `A` through `F` (representing the values 10 through 15)

### Why do computers use Hex?

In computing, everything boils down to binary (1s and 0s). However, binary strings get extremely long and difficult for humans to read.

Because 16 is a power of 2 ($2^4 = 16$), hexadecimal provides a very clean, human-readable shorthand for binary data. Exactly one hexadecimal digit represents four binary digits (a "nibble"). Two hexadecimal digits perfectly represent one 8-bit byte.

For example, the binary byte `01001000` is simply `48` in hex. This makes memory addresses, error codes, and color values (like HTML `#FFFFFF`) much easier for programmers to read and write.
