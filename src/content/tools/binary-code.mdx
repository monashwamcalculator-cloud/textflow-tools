## What is Binary Code?

Binary is the fundamental language of all computers. While humans typically use a base-10 numbering system (0-9) and a 26-letter alphabet, computers operate using transistors that only have two states: **on** or **off**. 

In binary, these states are represented as `1` (on) and `0` (off). Every character you type on a keyboard is translated by the computer into a specific sequence of these 1s and 0s using an encoding standard like ASCII or Unicode.

## The ASCII Standard

Our binary translator uses the ASCII (American Standard Code for Information Interchange) encoding standard. In ASCII, each character is represented by an 8-bit sequence (a "byte").

## Frequently Asked Questions

### Why does a lowercase 'a' have a different binary code than an uppercase 'A'?
Computers treat uppercase and lowercase letters as completely separate characters. In the ASCII table, an uppercase 'A' is assigned the decimal value 65 (which is `01000001` in binary), while a lowercase 'a' is assigned the decimal value 97 (`01100001`).

### How many bits are in a byte?
There are 8 bits (a single 0 or 1) in a standard byte. This is why our binary translator groups the 0s and 1s into blocks of eight.
