## How to Use the Alphabetizer

This tool helps you instantly organize messy data lists.

1. **Paste your list:** Enter your data into the left box. Ensure that each item is on its own separate line (the tool sorts line-by-line).
2. **Choose a Sort Order:**
   * **Alphabetical (A-Z):** Standard alphabetical sorting.
   * **Reverse Alphabetical (Z-A):** Sorts backwards from Z to A.
   * **Length (Shortest First):** Sorts items based on character count, putting the shortest words at the top.
   * **Length (Longest First):** Puts the longest words at the top.
3. **Ignore Capitalization:** By default, this is checked so that "apple" and "Zebra" sort correctly. If you uncheck it, uppercase letters will be sorted completely before lowercase letters based on standard computer logic (ASCII values).

## Common Uses for Sorting Tools

* **Teachers & Administrators:** Quickly alphabetizing student rosters or class lists.
* **Bibliographies:** Organizing citations in APA or MLA format.
* **SEO & Marketing:** Sorting large lists of keywords to find duplicates or organize them by string length.
* **Developers:** Organizing variables or CSS properties alphabetically for cleaner code structure.
