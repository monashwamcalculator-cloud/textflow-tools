## How to Use the Base64 Tool

Our Base64 utility can automatically detect whether you are trying to encode or decode text.

1. **Auto-Detect (Default):** Paste your text. If it looks like a valid Base64 string (containing only A-Z, a-z, 0-9, `+`, `/`, and padding `=`), the tool will decode it. Otherwise, it will encode your text into Base64.
2. **Force Encode:** If you have a string that happens to look like Base64 but you want to encode it *again*, select this mode.
3. **Force Decode:** Select this mode if you explicitly want to decode the input.

## What is Base64 Encoding?

Base64 is a data encoding scheme that translates binary data (like images or complex documents) into an ASCII string format. It uses a set of 64 characters:
* 26 uppercase letters (`A-Z`)
* 26 lowercase letters (`a-z`)
* 10 numbers (`0-9`)
* 2 symbols (`+` and `/`)

### Why use Base64?
Base64 is commonly used when there is a need to encode binary data that needs to be stored and transferred over media that are designed to deal with textual data. This ensures that the data remains intact without modification during transport.

Common use cases include:
* Embedding image files directly into HTML or CSS files.
* Sending email attachments via MIME (Multipurpose Internet Mail Extensions).
* Storing complex data in JSON or XML formats.

### Is Base64 Secure?
**No.** Base64 is an *encoding* scheme, not an *encryption* scheme. It is trivial for anyone to decode a Base64 string back to its original format. You should never use Base64 to hide passwords, secrets, or sensitive information.
